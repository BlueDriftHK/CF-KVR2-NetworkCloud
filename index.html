DEPLOY

5 分钟上线

不需要 Docker、不需要 VPS、不需要 CI/CD。复制粘贴即可。

1

创建 R2 存储桶

Dashboard → R2 → Create Bucket，命名 personal-drive（绑定名 DRIVE）。

2

创建 KV 命名空间

Dashboard → Workers → KV → Create，命名 STORE，记下 Namespace ID。

3

创建 Worker 并粘贴代码

Workers & Pages → Create Worker → 把 PersonalDrive_v5.1.2.js 全部内容粘贴到编辑器 → Deploy。

4

配置 Bindings

绑定 R2 DRIVE + KV STORE；Durable Object DIR 可选（不配自动降级）。

5

设置环境变量与 Secret

添加 DRIVE_PASSWORD（Secret），可选 DRIVE_QUOTA / TURNSTILE_* / IP_ALLOW 等。打开域名，开始用。

ARCHITECTURE

存储模型

三层存储各司其职，Durable Object 可选降级。

🪣

R2 — 文件存储

所有文件二进制存 R2（绑定 DRIVE），无出口流量费；缩略图 .thumb/、历史版本 .versions/、备份 .backup/ 均在此。

对象存储 · 零 Egress
🔑

KV — 元数据

目录索引、会话、标签、备注、分享链接、上传链接、活动日志、用量统计（绑定 STORE），JSON 序列化存储。

元数据 · 全球一致读
🧊

DO — 缓存加速

热目录缓存 + 原子用量计数（绑定 DIR，可选）。未配置时自动降级到 KV / 本地累加，不配也能完整运行。

可选 · 自动降级
