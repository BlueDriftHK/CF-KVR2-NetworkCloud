Deploy
5 分钟上线
不需要 Docker、不需要 VPS、不需要 CI/CD。复制粘贴即可。
1

创建 R2 存储桶

Dashboard → R2 → Create Bucket → 命名 drive

2

创建 KV 命名空间

Dashboard → Workers → KV → Create → 命名 STORE

3

创建 Worker 并粘贴代码

Workers → Create → 粘贴 _workers.js → Deploy

4

配置 Bindings

绑定 R2 DRIVE + KV STORE（DO DIR 可选）

5

设置环境变量

添加 DRIVE_PASSWORD，部署。打开域名，开始用。

Architecture
存储模型
三层存储各司其职，DO 可选降级。
🪣

R2 — 文件存储

所有文件二进制存 R2，无出口流量费。支持分片上传 (Multipart Upload) 处理大文件。

🔑

KV — 元数据

目录索引、会话、标签、备注、分享链接、活动日志、用量统计。JSON 序列化存储。

🧊

DO — 缓存加速

热目录缓存 + 原子用量计数。3s 超时自动降级到 KV，不配也能跑。
