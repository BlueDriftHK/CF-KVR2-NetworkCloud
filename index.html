为什么自建

把数据主权拿回来

商业网盘越用越贵、越用越受限。Personal Drive 让你用一份 Worker 的成本，拥有完全属于自己、可随时迁移的云盘。

💰

成本可控

R2 免出口费，KV/DO 按量计费。没有座位费、没有阶梯涨价，用多少付多少。

🔑

数据归属

文件就在你自己的 R2 桶里，随时可整体导出或迁移，不被平台绑定。

🌍

边缘速度

请求在离用户最近的 Cloudflare 节点响应，静态壳与资源可缓存，全球都快。

🧩

完全可改

单文件源码，前端全内联。想加字段、改界面、接 Webhook，几分钟搞定。

🛡️

隐私优先

服务端不持有明文密码（端到端加密可选），日志与分享都在你域内。

🚫

无广告无追踪

没有推荐流、没有行为分析，纯粹的文件工具。

快速开始

三步，拥有你的边缘云盘

克隆、配置绑定、一条命令上线。数据留在你自己的存储桶。

1

准备资源

创建 KV 命名空间、R2 存储桶、Durable Object 命名空间，记录各自 ID。

wrangler kv namespace create STORE
2

配置绑定

在 wrangler.toml 中把上述资源绑定为 STORE / DRIVE / DIR，并按需注入限流、Turnstile 等变量。

main = "_workers.js"
3

部署

部署后访问站点，设置管理员密码即可开始使用。

wrangler deploy

常见问题

关于 Personal Drive

大文件传一半断了怎么办？+
分片续传会记录已收分片，重传时服务端返回缺失下标，前端可仅补传缺失片；合并前还会做完整性校验，不再合并中途静默失败。
删除的文件能找回来吗？+
能。文件与目录删除都进入回收站，可单条或批量恢复；30 天内自动清理，并准确回退占用用量。
数据会被平台看到吗？+
文件本体存在你自己的 R2 桶。开启"可选端到端加密"后，服务端只存密文，密码在浏览器内派生、不离开本地。
能当网络硬盘挂载吗？+
可以。内置标准 WebDAV 接口，可挂载到系统文件管理器或第三方客户端，像本地磁盘一样使用。
分享链接会泄露内部信息吗？+
不会。分享页独立渲染，错误统一返回通用提示；访问计数仅在密码校验后计入，超限自动失效。
单文件有大小限制吗？+
默认单文件上限 500 MB（常量可调），超大文件建议分片上传；自动解包受 50 MB 上限保护以防 Worker 内存溢出。
