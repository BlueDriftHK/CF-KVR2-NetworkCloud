功能总览

一个网盘该有的，以及你没料到的

按七大类整理，每一项都在回归测试覆盖范围内。

🔐二次验证 TOTP

兼容任意验证器 App；启用时生成 8 个一次性备用码，服务端只存哈希。

🔒目录密码锁

任意目录（含根目录整体上锁）设密码；解锁状态随会话保留 10 分钟，锁定子树在搜索、复制、删除中一并受保护。

🎛分享级管控

禁止下载 / 仅预览、一次性下载、访问密码、IP·国家·UA 限制、访问次数上限、有效期，可随时删除。

🔑只读令牌

签发 ro 令牌给脚本或第三方集成：可读不可写，写接口统一返回 403。

⏱限时签名直链

带签名与过期时间的下载链接（默认 60 分钟，可调），适合外发给不支持 Cookie 的场景。

🚦风控与限流

读 150 / 写 30 次每分钟；登录按 IP 与用户名双维度 5 次/5 分钟；支持 IP·CIDR、国家、UA 黑白名单。

📋审计与告警

登录、上传、下载、删除、移动、恢复、配置变更全程留痕，可筛选并导出 CSV；异常登录可推 Webhook。

🖥设备与会话

列出登录设备逐个注销；改密即全体失效；KV 写入不可用时自动切换 HMAC 无状态会话，仍可登录。

🧬输入闸门

文件名净化、路径长度上限 400、KV 键校验、属性转义；远程抓取做协议白名单、主机黑名单、DNS 解析后校验与逐跳重定向检查。

⬆上传队列

多文件并发 1–6，可暂停 / 继续 / 取消 / 重试，逐文件进度与状态。

🧩分片上传

超过 5MB 自动切片（5MB/片），装配后校验大小；孤儿分片由定时任务回收。

⏯断点续传

中断任务被记录，刷新或重开页面后可一键恢复。

⚡秒传

按内容哈希识别已存在的文件，命中即落记录，不重复上传。

📝在线编辑

文本文件直接在线编辑并保存，无需下载再上传。

📦打包与解压

目录流式 ZIP 下载（上限 2000 文件 / 2GB）、压缩包解压、多选批量下载。

🕰版本与回收站

覆盖自动留版本（单文件最多 5 份，≤64MB）；删除进回收站保留 30 天，可单条或批量恢复。

🧬客户端加密

浏览器内 AES 加密后再上传，服务端只存 .enc 密文，密钥不离开你的设备。

📋批量操作

多选后批量删除 / 重命名（支持 {n} 序号）/ 移动 / 下载 / 打包 / 分享。

🔗文件与目录分享

独立分享页，可浏览子目录并打包下载整个文件夹。

🔖自定义短链

/s/<别名>（2–32 位字母数字下划线），可随时更换或清除，换别名即旧链接失效。

💬访客留言

站内与访客共用一套评论，可开关，新留言可推送 Webhook。

📈访问统计

浏览与下载计数、最近访问明细（含国家、浏览器、设备）；写盘有节流，不刷爆额度。

🎨分享外观

自定义标题、描述、主题色与给访客的提示语。

📤公开上传页

/upload 接收匿名上传，可指定目标目录、限制大小、启用 Turnstile 人机验证。

📥上传链接

/u/<token> 限时收件箱：给别人一个上传入口，不用给账号。

🗂批量分享

多选文件一次生成多个分享链接，便于逐项分发。

🧾下载明细

区分预览与下载，可导出核对，用于排查异常访问。

📄Office 预览

docx / xlsx / csv / ods 在线渲染（输出经净化；解析库按需加载，失败自动降级为下载）。

🎵音乐播放器

播放列表、顺序 / 列表循环 / 单曲 / 随机、音量与模式记忆、ID3 封面、同名 LRC 歌词跟随。

🎬音视频播放

支持 Range 拖动播放，大文件边下边播。

🖼公开相册

/a/<id> 只读相册：可设密码、分页加载、原图下载、EXIF 拍摄时间分组、GPS 链接地图。

🔍相似图片

客户端 dHash 感知哈希 + 汉明距离分组，阈值可调，分批建立索引。

🖌图片批处理

批量缩放、JPEG 质量、旋转、文字水印；另存副本或覆盖（覆盖自动留版本）。

🪪缩略图

图片自动生成缩略图，随文件删除而清理，不额外占你的空间账单。

📊媒体清单

按类型汇总图片 / 音频 / 视频，支持排序与快速跳转。

🛡预览沙箱

HTML / SVG 等不可信内容以 CSP: default-src 'none'; sandbox 提供，脚本不执行。

🔎高级筛选

名称、类型、扩展名、大小区间、日期区间、标签（任一或全部）、仅收藏、是否递归、排序、分页。

🏷标签体系

标签计数与颜色、重命名合并、批量增删、多标签 AND/OR 筛选、按类型或年月自动打标。

⭐收藏分组

收藏可分组管理（新建 / 重命名 / 删除 / 加入 / 移出），与收藏本身互不影响。

🕘最近访问

记录最近打开的文件，一键回到上次的位置。

🧹重复与相似

按内容哈希找完全重复，按感知哈希找相似图片。

📤元数据导出导入

子树内文件的标签 / 备注 / 收藏 / 大小 / 时间导出为 JSON 或 CSV；导入只匹配已存在文件，可合并或覆盖。

🌲目录树与搜索

目录树按层并行加载；全盘文件名搜索按键即出。

🗒文件备注

给任意文件写备注，随元数据一起备份与导出。

📐目录用量

按目录统计体积与条目数，找出占用最大的目录。

🎛可视化配置面板

标题、Logo、配额、上传上限、版本与回收站策略、备份策略、防爆与限流、风控名单——改完即时生效（KV 覆盖环境变量）。

📏目录级规则

按目录设文件数上限、容量上限、单文件上限、扩展名白 / 黑名单；普通上传、分片、上传链接、公开上传、WebDAV 导入一并遵守。

⏰定时任务

TTL 过期清理（可进回收站或彻底删除）、清空目录、按月份自动归档；cron 触发或手动运行，单次处理有上限。

💾备份与恢复

增量快照只存变化目录并沿链合并；恢复前可看差异预览；份数与总占用双限；快照不含二次验证密钥。

🌐WebDAV

🩺健康检查

🧽孤儿扫描

🪞存储后端

🔔通知

深浅色跟随系统或手动切换；密度宽松 / 紧凑（默认紧凑）；主题色任意取色，全局一致。

安全与隐私

数据是你的，控制权也是

下面每一项都在代码里实现，并有对应的回归断言；发现漏洞请走私密渠道（见 SECURITY.md）。

🔑认证与会话

  • 口令加盐哈希；比较使用常量时间函数
  • 会话 7 天，可逐台注销，改密即全体失效
  • 可选 TOTP（SHA-1 / 6 位 / 30 秒）+ 8 个备用码
  • KV 不可用时切换 HMAC 无状态会话（界面会提示其不可提前吊销）

🚪授权与隔离

  • 目录密码（含根目录锁定），解锁随会话保留 10 分钟
  • 锁定子树在列表 / 搜索 / 查询 / 复制 / 移动 / 删除 / 打包中全部过滤
  • 只读令牌写操作一律 403
  • R2 内部前缀（.versions/.trash/.chunks/.thumb/.backup）对用户、分享、相册、WebDAV 全部不可见

🛡响应加固

  • HTML 与 API 禁止缓存；CDN-Cache-Control: no-store 防边缘缓存旧页面
  • X-Content-Type-Options: nosniff、Referrer-Policy: no-referrer
  • 不可信预览内容加沙箱 CSP，阻断脚本与外部加载
  • 下载走 attachment，避免浏览器内联执行

🕸SSRF 防护

  • 仅允许 http / https
  • 阻断 localhost、.local、.internal、.home.arpa 与私有 / 链路本地 / 云元数据地址段
  • DNS 解析后再校验，防域名解析绕过
  • 重定向逐跳校验；体积与超时上限；可一键关闭抓取功能

🚧滥用与配额保护

  • 读写分桶限流 150 / 30 次每分钟（可选 DO 精确模式）
  • 登录 IP + 用户名双维度 5 次 / 5 分钟
  • 公开上传可选 Turnstile 人机验证
  • 额度紧张时优先暂停遥测写入，保证登录与元数据可用

🗄数据保护与审计

  • 覆盖留历史版本；删除进回收站（30 天）
  • 备份快照不含二次验证密钥；恢复前可看差异
  • 操作日志可筛选并导出 CSV；登录与评论可推 Webhook
  • 可选客户端 AES 加密上传（服务端只存密文）

✅部署安全清单（4 条，做完就挡住了大多数风险）

  • 用 16 位以上随机口令，并单独设置 URL_SIGN_SECRET（与口令解耦，便于单独轮换）
  • 开启二次验证并把备用码离线保存；给脚本用只读令牌而不是管理员口令
  • 公开上传页要么关闭，要么挂 Turnstile 并限制目标目录与大小
  • 分享链接一律设有效期；重要文件先在客户端加密；定期做一次备份恢复演练

完整威胁模型、密钥轮换步骤与事件响应流程见仓库 SECURITY.md。

⚠️本方案不提供的

  • 多租户隔离（单管理员模型，适合个人或小团队自用）
  • 端到端加密的完整实现（仅提供单文件客户端加密上传）
  • 硬件密钥 / WebAuthn（只有 TOTP）
  • 合规认证、SLA 与商业支持

📌已知取舍

  • 未启用严格 CSP / SRI（内联资源过多，改造风险大）
  • WebDAV 目录 MOVE/COPY 返回 501；Depth: infinity 按 1 处理
  • 口令哈希为单轮加盐 SHA-256（弱于 PBKDF2/Argon2）
  • 预览依赖按需加载的 CDN 库（失败自动降级）

🎯什么场景最合适

  • 个人文件集中存放 + 自己域名访问
  • 给家人/小团队一个共享空间
  • 需要 WebDAV 挂载到系统当磁盘用
  • 想把"数据在谁手里"这件事攥紧
技术架构

跑在边缘，轻量却完整

视图层：内嵌 SPA（HTML / CSS / JS 同文件）+ 公开页 + Service Worker
↓
📦 R2 · 绑定 DRIVE 必需
文件本体；内部前缀 .versions/ .trash/ .chunks/ .thumb/ .backup/ 对用户不可见。
🗃 KV · 绑定 STORE 必需
目录元数据、会话、站点配置、统计与各类索引（带 TTL）。元数据的唯一真相源。
🧠 DO · 绑定 DIR 可选
目录索引加速（类名 DirStore）。不绑定时自动回退 KV 模式，功能一致、仅并发与大目录略慢。

🔁DO 是加速层不是依赖

DO 实例被回收或清空时会从 KV 重新播种；大目录超出 DO 单值上限（96KB 安全余量）时自动走 KV 合并路径。

🧱单文件不是偷懒

换来"拷走即用 + 无供应链风险 + 无构建链断裂"；代价是阅读成本，因此回归断言与文档要求更严。

📉无 npm 依赖

运行时依赖为 0，部署物就是那一个文件；开发期也只依赖 Node 跑回归（离线、内存仿真）。

快速开始

三步，拥有你的边缘网盘

两种方式任选：控制台粘贴（最快）或 wrangler（便于版本管理）。免费额度即可运行。

  1. 创建 Worker：Cloudflare 控制台 → Workers & Pages → 创建 Worker。
  2. 粘贴代码：打开仓库里的 _workers.js → 全选复制 → 编辑器里全选替换 → Deploy。
  3. 加绑定与变量：Settings 里添加 DRIVE（R2）、STORE（KV），可选 DIR（DO，类名 DirStore）；环境变量加 DRIVE_PASSWORD。

✅部署后 3 步自检

  • 访问 /api/version：应返回 version、ui 与 bindings（其中 store / drive 必须为 true）
  • 登录后上传一个文件 → 预览 → 刷新确认仍在
  • 看页面底部状态条：应显示 v5.2.0 · flat-1（这是判断线上版本是否生效的最快方式）

常见问题

你大概会问这些

一定要绑定 Durable Object 吗？

不。DIR 是可选的加速层。不绑定时目录索引走 KV，功能完全一致，只是并发改写与大目录遍历会慢一些。绑定后遇到超出 DO 单值上限的大目录，也会自动回退 KV 合并路径。

免费额度够用吗？会不会被限流？

代码就是按免费额度设计的：默认每日遥测写预算 500 条（KV 免费额度是每天 1000 次写），并有多级读缓存、每分钟写预算与内存缓冲合并。个人日常使用通常远低于额度。

即使触发限制，也是先暂停遥测类写入（日志、最近访问），登录与目录元数据等关键写入照常——不会"为了统计把服务写死"。

备份包含文件内容吗？

不包含。快照只存元数据（目录树、标签、备注、分享、上传链接、目录密码、收藏、最近、用量），并且不含二次验证密钥。文件本体在 R2 里，所以请另外为重要文件保留离线副本——备份恢复不等于文件备份。

支持多大的文件？

默认单文件上限 500MB（可在站点配置面板调整），超过 5MB 自动走分片上传（5MB/片），装配后校验大小。实际上限还受 Cloudflare 请求体限制与你的套餐影响。

能用自己的域名吗？

可以。给 Worker 配置 Custom Domain（或 Route）即可。仓库里的 CNAME 与 index.html 用于 GitHub Pages 展示页，与 Worker 的访问域名互不影响。

分享链接怎么做得更安全？

组合使用：访问密码 + 有效期 + 访问次数上限 + 一次性下载 + 禁止下载（仅预览）+ IP / 国家 / UA 限制 + 自定义短链（换别名即旧链接失效）。对特别敏感的文件，先在客户端加密上传（服务端只存 .enc 密文）。

WebDAV 能挂载吗？有什么限制？

可以，地址是 https://<你的域名>/dav/，用户名任意、口令为管理员口令。Windows「映射网络驱动器」、macOS「连接服务器」、Linux davfs2 都行。

限制：目录级 MOVE/COPY 返回 501（请用站内"移动/复制"），Depth: infinity 按 1 处理（避免一次 PROPFIND 打爆配额）。

怎么确认线上跑的是最新版？

看页面底部状态条（形如 v5.2.0 · flat-1），或访问 /api/version 看 version 与 ui 字段。两者都带界面构建号，专门用于判断"部署有没有生效"。HTML 响应已禁用边缘缓存，刷新即生效。

升级会丢数据吗？

不会。数据在 R2 / KV 里，Worker 只是代码，升级＝粘贴新代码再部署。但绑定改名或 KV 结构变化属于破坏性变更，会在发布说明里标注，建议先读再升。回滚也简单：重新部署上一版代码即可。

和商业网盘相比，我失去了什么？

主要是"省心"：你要自己配置绑定、自己升级、自己处理故障；没有多租户隔离（单管理员模型）、没有硬件密钥登录、没有商业 SLA 与合规认证、没有端到端加密的完整实现（仅单文件客户端加密）。换来的是数据位置、源码可控与迁移自由。

几分钟，拥有属于你的网盘

一个文件、两个绑定、一个口令。数据在自己的存储桶里，代码在自己的手里。
