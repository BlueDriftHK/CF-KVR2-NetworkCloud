Security by default

数据是你的，
控制权也是。

没有第三方账号体系，没有云端扫描。安全不是一个开关，而是贯穿每个端点的默认值。

认证与会话

管理员密码使用 PBKDF2 派生；支持 TOTP 动态码与一次性备用码；会话 / 访问令牌分离，改密即吊销。

  • 密码 / 动态码 / 备用码三选一验证
  • 只读令牌：可读不可写
  • 登录按 IP 与用户名双维度限频
PBKDF2 · TOTP RFC 6238

授权与隔离

目录密码锁保护指定子树；分享权限细化到下载、评论、IP、国家、UA、次数与单次；内部命名空间不可经 API 读写。

  • 目录锁：搜索 / 复制 / 删除一并生效
  • 签名直链：过期时间 + IP 绑定
  • 一次性分享原子消费，Range 不能绕过
Folder lock · Signed URL

动态验证码

启用二次验证后，登录需要验证器 App 中的 6 位动态码；备用码只在首次生成时展示一次，服务端仅存哈希。

0 个外部依赖没有 npm 供应链，也没有随包引入的第三方脚本

所有静态资源启用 SRI（7 个），页面设有 CSP 与 X-Frame-Options；上传内容默认以沙箱方式预览，HTML / SVG 等不可信类型强制降级为纯文本。防护做在默认值里，而不是文档里。

Specifications

边界写死，
行为可预期。

所有上限都可以在配置面板或环境变量中调整；下面是默认值，也是"不会被静默突破"的那条线。

Bindings

  • 对象存储R2 · DRIVE
  • 元数据 / 索引KV · STORE
  • 一致性（可选）DO · DIR
  • 管理员密码Secret · DRIVE_PASSWORD
  • 自检/api/version

Limits

  • 单文件上传500 MB
  • 简单上传（直传）≤ 100 MB
  • 分片大小5 MB
  • 单目录条目20,000
  • 路径长度≤ 400 字符

Retention

  • 历史版本5 份 / 单份 ≤ 64MB
  • 回收站30 天
  • 未完成分片24 小时
  • 备份快照14 份 / 200MB
  • 分享打包2000 文件 / 2GB

Security

  • 口令派生PBKDF2-SHA256
  • TOTP 窗口30s · ±1 step
  • 会话有效期7 天
  • 签名直链默认60 分钟
  • 媒体令牌10 分钟

FAQ

你可能想问的。

文件存在哪里？我真的拥有它们吗？
文件存放在你自己的 Cloudflare R2 桶里，元数据在你的 KV 命名空间里。Worker 只是访问入口，不经过任何第三方服务；你可以随时导出、迁移或删除整个桶。项目本身也可以完全自托管于你的账号下。
单文件会不会很难维护？
它刻意保持"一个文件、复制即用"的部署体验：没有构建链、没有依赖版本冲突。代码内按 Helpers / Auth / API / Share / WebDAV / Frontend 分区组织，并配有 200+ 项自建断言与一份可复现的代码审查记录。
免费额度够用吗？
个人使用通常足够：R2 有免费存储额度，Workers 免费计划提供每日请求额度。项目内置了 KV 写预算、遥测预算、R2 体积上限、版本与回收站自动回收等"防爆"机制，避免误把免费额度刷爆。
能当团队盘用吗？
它被设计为"单管理员的个人网盘"：一个管理员密码 + 可选 TOTP，没有多用户账号体系。团队场景可以给成员签发只读 / 读写访问令牌，或通过分享链接与公开上传页协作。
手机能用吗？
可以。前端是响应式的，支持 PWA 添加到主屏幕、系统分享面板直接上传、移动端手势（右滑返回、左滑多选、长按菜单、下拉刷新）以及离线只读浏览。
代码规模这么大，为什么坚持单文件？
因为部署体验是产品的一部分：把文件粘进 Dashboard 就能跑，不需要 Node、构建缓存或依赖审计。代价是仓库内需要更严格的分区与测试，这一点由文件内的分区注释、200+ 项断言和代码审查记录来补足。
如果 Cloudflare 免费额度用完了？
项目内置了限流、KV 写预算、遥测预算与体积上限，会优先"省着用"而不是静默失败；超出后可以升级 Workers / R2 套餐，或把 R2 数据迁到别的兼容存储（代码内置 S3 兼容镜像后端）。
有没有多语言 / 无障碍支持？
内置中英双语切换、浅色 / 深色 / 跟随系统三态主题；组件使用语义化标签与键盘焦点样式，命令面板支持纯键盘操作，并尊重系统"减少动态效果"设置。
