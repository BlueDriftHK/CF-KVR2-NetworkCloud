# ☁️ Personal Drive

> 部署在 Cloudflare 边缘的私有网盘 · **v5.1.2**
> 基于 **R2 + KV + Durable Object** 构建，Apple 风界面，开源、可自托管，数据始终留在你自己的存储桶中。

---

Personal Drive 是一个单文件（single-file）的 Cloudflare Worker 网盘应用：前端页面全部内联，后端逻辑、鉴权、存储编排都在同一个 `_workers.js` 里。它把**大文件切片续传、受控分享、回收站、版本历史、可选端到端加密、WebDAV、远程下载**等能力，浓缩进一份可直接 `wrangler deploy` 的脚本。

- 🪶 **轻量**：无服务器、无独立后端，按量计费、贴近用户的边缘延迟。
- 🔒 **自用可控**：管理员密码、令牌、文件夹锁、IP 名单，权限边界清晰。
- 🎨 **好看**：毛玻璃 + 大圆角 + 柔光，浅色 / 深色 / 跟随系统三主题。
- 🧩 **完整**：从日常存取到大文件归档，一个网盘该有的都有。

## ✨ 功能特性

### 🗂️ 文件管理
- **三种视图**：网格、列表、图库（照片自动走大图模式）。
- **基础操作**：新建文件夹、重命名、移动、复制路径、在线编辑文本文件。
- **批量操作**：批量删除、批量重命名（支持规则）、批量移动、批量分享、批量恢复/清除回收站。
- **面包屑导航 + 目录树**：深目录也能快速跳转。

### ⬆️ 上传与下载
- **分片续传**：大文件自动切片上传（默认 ≤5MB/片），断点可续。
- **完整性预检**：合并前以"已收分片清单"校验，缺片明确返回 `missing` 下标，便于前端续传，不再合并中途静默失败。
- **秒传去重**：按内容哈希识别已存在文件，相同内容即时落盘。
- **拖拽即传**：拖文件进窗口即上传，进度条实时、失败可重试。
- **范围下载 / 在线预览**：图片、视频、音频、文本、PDF 均可流式预览；支持 HTTP Range。

### 🔗 分享与协作
- **文件 / 目录分享**：生成独立分享链接，目录分享有专属浏览页。
- **受控参数**：可设**访问密码**、**有效期（1–3650 天）**、**最大访问次数**（超限自动失效）。
- **访问计数**：仅在密码校验通过后计入，避免匿名刷爆配额。
- **公开上传页**：可开启免登录公开上传，支持 **Turnstile** 人机验证，按链接/目录限制文件数与有效期。

### 🗑️ 回收与版本
- **回收站**：文件与**目录**删除均进入回收站（目录整体暂存、可完整恢复），30 天自动清理并准确回退用量。
- **版本历史**：每次覆盖自动留存历史版本（默认 5 份），可一键回滚。

### 🔍 搜索与整理
- **全局搜索**：关键词检索文件/目录。
- **重复文件查找**：快速定位内容重复项。
- **标签系统**：给文件打标签并据此筛选。
- **收藏 / 最近访问**：常用文件一键置顶。

### 🖼️ 媒体与相册
- **相册**：把目录整理成公开相册，支持灯箱大图、幻灯片播放。
- **缩略图 / EXIF**：图片自动生成缩略图，预览展示 EXIF 信息。
- **ZIP**：目录一键打包下载；上传压缩包可自动解包进目录（受 `UNZIP_MAX_BYTES` 上限保护）。

### 🤖 自动化
- **自动归档规则**：按扩展名/类型自动归类（如压缩包自动解包）。
- **远程下载（Fetch URL）**：粘贴外链，由边缘节点拉取入库，本机无需中转。
- **备份与快照**：手动或每日自动快照，可整体恢复；支持存储后端镜像（Mirror）冗余。
- **每日快照**：调度任务自动生成，避免误删。

### 🔐 安全与权限
- **可选端到端加密**：浏览器内基于密码派生密钥加密，服务端只存密文，密码不离开本地。
- **文件夹密码锁**：对任意目录加锁，锁定子树禁止被移动/删除绕过；分享也需先解锁。
- **IP 白 / 黑名单**：按 IP 段放行或拒绝（环境变量配置，未配置则放行）。
- **访问令牌**：签发独立令牌，支持**只读（ro）/ 读写（rw）**，适合嵌入展示或第三方只读集成。
- **按令牌限流**：Durable Object 令牌桶对读/写分别限流（默认 150/分、30/分），防单令牌刷爆 KV 配额；DO 故障时 fail-open 放行。
- **管理员会话**：登录会话可查看与吊销，支持修改管理员密码。
- **安全响应头**：API 响应默认 `no-store` 不缓存、`nosniff` 防 MIME 嗅探；错误信息统一为通用提示，不泄露内部细节。

### 🛠️ 管理与运维
- **用量统计**：实时容量进度、上传/下载趋势、操作日志。
- **健康检查 / 孤儿清理**：自检存储一致性，扫描并清理游离对象。
- **Webhook**：关键事件可回调通知。
- **存储后端镜像（Mirror）**：配置 S3 兼容后端做冗余。

### 📡 协议与集成
- **WebDAV**：标准接口，可挂载到系统或第三方客户端，像本地磁盘一样使用。
- **PWA**：内置 Service Worker 与清单，可"添加到主屏幕"，离线壳、近原生体验。

### 🎨 界面与体验
- **Apple 风设计**：毛玻璃卡片、20px 大圆角、柔光背景。
- **三态主题**：浅色 / 深色 / 跟随系统，偏好本地记忆，所有内联页一致。
- **全宽网格**：顶部面包屑 + 全宽文件区，无侧栏干扰（☰ 仍可唤出侧栏）。
- **响应式**：桌面与移动端同样顺手。

## 🧱 技术架构

```
            ┌─────────────────────────────┐
   用户 ──▶ │   Cloudflare 边缘节点 (Worker) │
            │   路由 / 鉴权 / 限流 / 主题     │
            └──────────────┬──────────────┘
                           │
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
      ┌────────┐      ┌──────────┐     ┌──────────────┐
      │  R2    │      │   KV    │     │ Durable Object│
      │ 存储   │      │ 元数据   │     │ 用量 / 限流   │
      │文件/缩略│      │目录/标签 │     │ (原子一致)    │
      │/版本   │      │/分享/令牌│     │              │
      └────────┘      └──────────┘     └──────────────┘
```

| 层 | 职责 |
|---|---|
| **Worker（_workers.js）** | 路由分发、鉴权、限流、前端页面渲染、上传/下载编排 |
| **R2** | 文件本体、缩略图、历史版本（低延迟、免出口费） |
| **KV** | 目录清单、标签、笔记、分享记录、访问令牌、用量等结构化数据 |
| **Durable Object** | 用量计数与限流令牌桶，保证并发下的原子一致 |

**关键常量**（位于 `_workers.js` 顶部）：

| 常量 | 默认值 | 说明 |
|---|---|---|
| `MAX_UPLOAD_SIZE` | 500 MB | 单文件上传上限 |
| `UNZIP_MAX_BYTES` | 50 MB | 自动解包体积上限（防 Worker 内存溢出） |
| `MAX_VERSIONS` | 5 | 保留的历史版本数 |
| `USAGE_DO_NAME` | `__usage__` | 用量 Durable Object 名称 |

## 🚀 部署

### 前置条件
- 一个 Cloudflare 账号，已开通 **R2** 与 **Workers**。
- 已安装 `wrangler`（`npm i -g wrangler`）。
- 一个 **KV 命名空间**、一个 **R2 存储桶**、一个 **Durable Object 命名空间**。

### 1. 准备绑定
在 Cloudflare 控制台或通过 `wrangler` 创建以下资源，并记录其 ID：

- KV 命名空间 → 绑定名 `STORE`
- R2 存储桶 → 绑定名 `DRIVE`
- Durable Object 命名空间 → 绑定名 `DIR`

### 2. 示例 `wrangler.toml`
```toml
name = "personal-drive"
main = "_workers.js"
compatibility_date = "2024-09-23"

[[kv_namespaces]]
binding = "STORE"
id = "你的_KV_命名空间_ID"

[[r2_buckets]]
binding = "DRIVE"
bucket_name = "your-bucket-name"

[[durable_objects.bindings]]
name = "DIR"
class_name = "Dir"          # 与 _workers.js 中 env.DIR 对应的 DO 类

# 可选：镜像后端 / 人机验证 / 限流阈值等通过 vars 注入
[vars]
RL_READ_PER_MIN = "150"
RL_WRITE_PER_MIN = "30"
# TURNSTILE_SECRET = "0x...."
# TURNSTILE_SITE_KEY = "0x...."
```

> 注：`class_name` 需与你的 Durable Object 类定义一致；本仓库 `_workers.js` 通过 `env.DIR.idFromName(...)` 使用，命名为 `DIR` 即可。

### 3. 配置环境变量（可选）
| 变量 | 默认值 | 说明 |
|---|---|---|
| `RL_READ_PER_MIN` | 150 | 每令牌每分钟读请求上限 |
| `RL_WRITE_PER_MIN` | 30 | 每令牌每分钟写请求上限 |
| `TURNSTILE_SECRET` | 空 | Cloudflare Turnstile 私钥（开启公开上传验证） |
| `TURNSTILE_SITE_KEY` | 空 | Turnstile 站点公钥 |
| `IP_ALLOW` / `IP_DENY` | 空 | IP 白/黑名单（逗号分隔的 CIDR 或地址） |

### 4. 部署
```bash
wrangler deploy
```
部署后首次访问会进入登录页，**请先设置管理员密码**（通过 `/api/admin-pass` 或页面内设置）。

## 🔐 安全模型

1. **鉴权边界**：除登录、公开分享、公开上传、相册/分享静态页外，所有 `/api/*` 均需 Bearer 令牌。
2. **只读令牌**：`ro` 令牌仅允许 GET/HEAD，写操作返回 `403`。
3. **路径安全**：所有路径经 `normPath` 规范化（`..` 被解析），目录锁定子树在移动/删除前被校验。
4. **限流**：按令牌维度读写分别限流，保护 KV 配额不被单点刷爆。
5. **内容加密（可选）**：端到端加密在浏览器内完成，服务端不持有明文密码。
6. **信息收敛**：异常统一返回 `Internal error`，不向客户端暴露堆栈或内部路径。

## 💡 使用技巧

- **大文件传一半断了？** 分片续传会记录已收分片，重传时服务端返回缺失下标，前端可仅补传缺失片。
- **想当网络硬盘用？** 开启 WebDAV，把网盘挂载到系统文件管理器。
- **分享给别人限时看？** 创建分享时设"有效期 + 最大访问次数"，到点自动失效。
- **怕误删？** 删除进回收站，30 天内随时恢复；重要目录记得开文件夹密码锁。
- **批量整理照片？** 配置自动归档规则，上传压缩包自动解包、图片自动进图库视图。
- **主题跟随系统？** 点右上角 🌗 在 跟随系统 / 浅色 / 深色 间循环，偏好本地保存。

## 🗺️ 已知限制

- **并发用量计数**：当未配置 Durable Object（仅 KV 回退）时，用量计数为最终一致，极端并发下可能有微小偏差；默认部署含 DO，已原子化。
- **分片续传前端**：服务端已能返回缺片清单（`canResume`），前端续传 UI 需相应接线后方能真正断点续传。
- **单文件上限**：受 `MAX_UPLOAD_SIZE` 与 Worker 内存约束，超大文件建议分片或走 R2 直传方案。
